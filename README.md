# Chrome HoverTrans

Расширение Google Chrome для перевода английского слова на русский: навести курсор, удерживать **Ctrl**, остановить мышь на **500 мс**. Перевод появляется над курсором; желательны примеры употребления и кнопка английского произношения.

## Текущее состояние

Подготовлена документация. Кода расширения, `manifest.json`, зависимостей и исполняемых команд сборки пока нет. Провайдер перевода ещё не проверен из расширения. Следующий этап — реализация, начиная с HT-01.

## Локальная разработка

Репозиторий предназначен для локальной работы; remote и публикация не нужны. Проверить состояние: `git status --short`, историю: `git log --oneline`, отсутствие remote: `git remote -v`.

После появления реализации HT-02 добавит команды установки, тестирования и сборки. Планируется загрузка каталога `dist/` через `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение». Сейчас загружать нечего.

Внешним сервисам будет отправляться выбранное слово. Не использовать расширение для конфиденциального текста; подробности границ передачи данных — в [архитектуре](docs/ARCHITECTURE.md).
