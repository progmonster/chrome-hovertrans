# Chrome HoverTrans

Расширение Google Chrome для перевода английского слова на русский: навести курсор, удерживать **Ctrl**, остановить мышь на **500 мс**. Карточка над курсором показывает перевод MyMemory, доступные примеры Free Dictionary API / Wiktionary и кнопку английского произношения локальным голосом Chrome.

## Текущее состояние

Реализована локальная версия **0.1.0** на Manifest V3. Перевод, примеры и завершение речи проверены через установленное расширение в Google Chrome на macOS. Регистрация, API-ключ, карта и собственный сервер не нужны. Квота и доступность бесплатного API ограничены провайдером; автоматического перехода на платный сервис нет.

## Сборка и установка

Нужен Node.js 24 LTS (проверено на 24.18.1, версия в `.nvmrc`).

```sh
npm ci
npm test
npm run build
```

В Chrome откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите **`dist/`** из этого проекта. Именно там лежит готовый `manifest.json`; корень проекта загружать не нужно. Расширение уже загружено в Chrome при проверке этой версии.

После установки обновите нужную веб-страницу. Наведите курсор на английское слово и удерживайте Control 500 мс; на Mac это **Control, не Command**. Отпустите клавишу и перейдите к карточке, чтобы нажать «Произнести». Esc или прокрутка закрывают окно.

После изменений: `npm run build`, кнопка перезагрузки HoverTrans в `chrome://extensions`, затем обновление тестовой страницы. Готовая сборка `dist/` не хранится в Git и восстанавливается одной командой.

## Проверка локально

```sh
npm run dev:fixture
```

Откройте `http://127.0.0.1:8765`. Есть синтетические слова, поля-исключения и кнопка «Проверить расширение». Она отправляет тестовые события настоящему content script и использует живой API; физическую клавишу Ctrl и удобство перехода к окну дополнительно проверьте вручную. Остановка сервера — Ctrl+C в его терминале.

`npm test` запускает автономные тесты без сети. `npm run check:providers` — явная сетевая диагностика шести общеупотребительных тестовых слов и примеров `hello`; обычные тесты её не запускают.

## Ограничения и приватность

Работает в основном фрейме HTTP(S)-страниц. Поля ввода и редакторы исключены. PDF, iframe, Shadow DOM сайтов, `chrome://`, Chrome Web Store, файлы и инкогнито не поддерживаются в v1. Языки, Ctrl и 500 мс фиксированы.

MyMemory может давать неточный вариант многозначного слова; это не копия словаря Google Translate. Примеры есть не для каждого слова, загружаются отдельно и скрываются при сбое. Если локальный английский голос не установлен, кнопка объяснит недоступность. При сетевой ошибке повторите наведение с Ctrl; скрытых ретраев нет.

Расширению нужен доступ к тексту обычных сайтов для определения слова под курсором. При активации внешним сервисам отправляются только слово и фиксированное направление, без URL и контекста страницы, cookies и истории. Провайдеры видят IP и сетевые метаданные; не переводите конфиденциальные слова. Постоянного хранения истории, аналитики и загрузки удалённого кода нет.
