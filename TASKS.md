## Реализация v1

- [ ] **HT-01 — Проверить бесплатную интеграцию.** Небольшой MV3-прототип: реальный EN → RU запрос из worker; выбрать провайдера без биллинга/секрета в клиенте. Проверить примеры и локальный английский TTS. Заполнить результат в PROVIDERS.md и ADR-003, определить минимальные origin/permissions, сохранить обезличенные fixtures. Мок и curl без браузерной проверки не закрывают задачу. При блокировке записать её и продолжать независимые части.
- [ ] **HT-02 — Каркас и воспроизводимая сборка.** Manifest V3, JS/esbuild, закреплённые Node LTS и lockfile, `npm test`, `npm run build`, локальная fixture. `dist/` загружается в Chrome без ошибок. README содержит проверенные команды установки, сборки, запуска fixture и перезагрузки расширения. Зависит от HT-01 только в части выбранных API-origin.
- [ ] **HT-03 — Слово и активация.** Поиск токена под координатами, Ctrl, 500 мс, допуск 4 px, исключённые поля и контексты. Проверки времени, сбросов, границ слова и отсутствия запроса без жеста; ручная проверка обоих порядков Ctrl/наведения. Зависит от HT-02.
- [ ] **HT-04 — Перевод и устойчивость.** Адаптер, валидация сообщений, тайм-аут, отмена, защита от устаревших ответов, изоляция вкладок, кэш и ограничение частоты. Реальная интеграция работает без отправки контекста страницы; ошибки проверены локально. Зависит от HT-01–HT-03.
- [ ] **HT-05 — Popup.** Shadow DOM, состояния загрузки/успеха/ошибки, позиционирование и границы viewport, переход к окну, доступные кнопки и закрытие. После отпускания Ctrl можно взаимодействовать с окном; ссылки и системные сочетания не ломаются. Зависит от HT-03–HT-04.
- [ ] **HT-06 — Примеры употребления.** Отдельный проверенный словарь, до двух английских примеров, атрибуция, независимая загрузка и мягкая деградация. Примеры не выдумываются и не блокируют перевод. Зависит от HT-01, HT-04–HT-05. При недоступности подходящего источника оставить задачу открытой с причиной; перенос согласовать с владельцем.
- [ ] **HT-07 — Английское произношение.** Кнопка через chrome.tts, только по клику и локальным английским голосом; выбор голоса, недоступность, ошибка, остановка своей речи при закрытии. Проверено в Chrome на целевом Mac. Зависит от HT-01, HT-05.
- [ ] **HT-08 — Приёмка и локальная версия v1.** Пройти релевантные автоматические проверки и ручную матрицу TESTING.md, проверить права/сеть, обновить README и ограничения, сохранить результат локальным коммитом. Не публиковать в Chrome Web Store. Непроверенные сценарии и приёмка владельца остаются явно открытыми. Зависит от HT-01–HT-07 либо согласованного переноса желательных функций.
