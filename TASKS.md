# Задачи проекта

## Текущее состояние

- Этап: локальная версия 0.1.0 реализована и загружена в Chrome; передаётся владельцу для проверки физического Ctrl.
- В работе: HT-08 — оставшаяся ручная приёмка владельца.
- Следующая задача: проверить физическую клавишу Ctrl и удобство перехода к карточке на своей странице.
- Ограничения: точная текущая квота MyMemory не подтверждена; у словаря возможны временные сетевые сбои. Перевод одиночного слова может быть контекстно неточным.

Чекбокс `[x]` означает выполненные критерии, `[ ]` — открыто, включая частичное выполнение. Результат и проверки записываем непосредственно под задачей. Требования: [PRODUCT.md](docs/PRODUCT.md), процесс: [WORKFLOW.md](docs/WORKFLOW.md).

## Реализация v1

- [x] **HT-01 — Проверить бесплатную интеграцию.** Небольшой MV3-прототип: реальный EN → RU запрос из worker; выбрать провайдера без биллинга/секрета в клиенте. Проверить примеры и локальный английский TTS. Заполнить результат в PROVIDERS.md и ADR-003, определить минимальные origin/permissions, сохранить обезличенные fixtures. Мок и curl без браузерной проверки не закрывают задачу. При блокировке записать её и продолжать независимые части.
  - Результат 2026-10-17: Выбран MyMemory; перевод и примеры проверены из установленного MV3 worker. Локальный TTS завершил речь без ошибки. Источники, реальные fixtures, качество и неопределённость квоты записаны в PROVIDERS.md.
- [x] **HT-02 — Каркас и воспроизводимая сборка.** Manifest V3, JS/esbuild, закреплённые Node LTS и lockfile, `npm test`, `npm run build`, локальная fixture. `dist/` загружается в Chrome без ошибок. README содержит проверенные команды установки, сборки, запуска fixture и перезагрузки расширения. Зависит от HT-01 только в части выбранных API-origin.
  - Результат 2026-10-17: Node 24.18.1, esbuild 0.28.2, lockfile, npm ci/test/build и dev:fixture проверены. dist/ загружен в Chrome 155.0.8059.80. AGENTS.md сохранён.
- [x] **HT-03 — Слово и активация.** Поиск токена под координатами, Ctrl, 500 мс, допуск 4 px, исключённые поля и контексты. Проверки времени, сбросов, границ слова и отсутствия запроса без жеста; ручная проверка обоих порядков Ctrl/наведения. Зависит от HT-02.
  - Результат 2026-10-17: Реализованы Ctrl/500 мс/4 px, caret + Range, исключения DOM. Автономные тесты и браузерный прогон синтетических событий прошли; физический Ctrl оставлен владельцу по допустимому варианту проверки.
- [x] **HT-04 — Перевод и устойчивость.** Адаптер, валидация сообщений, тайм-аут, отмена, защита от устаревших ответов, изоляция вкладок, кэш и ограничение частоты. Реальная интеграция работает без отправки контекста страницы; ошибки проверены локально. Зависит от HT-01–HT-03.
  - Результат 2026-10-17: Реализованы worker, MyMemory, валидация, тайм-аут, AbortController, актуальность ответа, кэш, throttling и cooldown. Проверены автономно; живые hello и domain получены в Chrome на HTTP и HTTPS.
- [x] **HT-05 — Popup.** Shadow DOM, состояния загрузки/успеха/ошибки, позиционирование и границы viewport, переход к окну, доступные кнопки и закрытие. После отпускания Ctrl можно взаимодействовать с окном; ссылки и системные сочетания не ломаются. Зависит от HT-03–HT-04.
  - Результат 2026-10-17: Shadow DOM popup визуально осмотрен в Chrome: перевод, вариант, два примера, источники и кнопка. Синтетически проверены задержка, отпускание Ctrl, Esc, viewport и поле ввода; ручные сценарии перечислены в TESTING.md.
- [x] **HT-06 — Примеры употребления.** Отдельный проверенный словарь, до двух английских примеров, атрибуция, независимая загрузка и мягкая деградация. Примеры не выдумываются и не блокируют перевод. Зависит от HT-01, HT-04–HT-05. При недоступности подходящего источника оставить задачу открытой с причиной; перенос согласовать с владельцем.
  - Результат 2026-10-17: Free Dictionary API возвращает примеры с лицензией и ссылкой Wiktionary. Сетевой сбой скрывает раздел, не перевод; успешный отдельный поиск показал два примера в реальной карточке.
- [x] **HT-07 — Английское произношение.** Кнопка через chrome.tts, только по клику и локальным английским голосом; выбор голоса, недоступность, ошибка, остановка своей речи при закрытии. Проверено в Chrome на целевом Mac. Зависит от HT-01, HT-05.
  - Результат 2026-10-17: Локальный английский голос найден на Mac; нажатие кнопки из браузерного прогона завершило TTS без ошибки. Тесты покрывают ошибку движка, отмену до получения голоса и изоляцию остановки по вкладкам.

Не публиковать в Chrome Web Store. Непроверенные сценарии и приёмка владельца остаются явно открытыми. Зависит от HT-01–HT-07 либо согласованного переноса желательных функций.
  - Готовая сборка и проверка доступными средствами переданы владельцу: 23 теста, воспроизводимая установка/сборка, живой перевод на HTTP/HTTPS, примеры и TTS. Локальный коммит без remote. Открыто: физическое удержание только Ctrl, переход мышью, Ctrl+C/Ctrl+click и zoom/крайние размеры; инструмент отклоняет одиночный модификатор.
