# Требования к v1

## Цель

Быстро узнать русский перевод английского слова при чтении веб-страницы, без выделения текста и переключения вкладки. Первая версия устанавливается локально как распакованное расширение Google Chrome Desktop. Первичная ручная приёмка — на macOS; другие ОС не объявляем проверенными без проверки.

## Зафиксированные параметры

Это исходные проектные решения, а не пользовательские настройки. Меняем их только явным изменением требований.

| Параметр | V1 |
| --- | --- |
| Направление | `en` → `ru`, без автоопределения |
| Модификатор | настоящий `Ctrl` (`ControlLeft` / `ControlRight`); на Mac не `Command` |
| Неподвижность | `HOVER_DELAY_MS = 500` |
| Допуск дрожания | `POINTER_TOLERANCE_PX = 4` CSS px от точки начала ожидания |
| Длина слова | до 64 символов |
| Сетевая задержка | тайм-аут перевода 5000 мс, дополнений 3000 мс |
| Popup | отступ 12 px от курсора, ширина до 360 px с учётом viewport |
| Переход к popup | 300 мс на перемещение от слова к окну |

## Активация

1. Курсор находится над видимым английским словом в обычном DOM-тексте. Подходят латинские буквы, внутренние апострофы и дефисы: `hello`, `don't`, `well-known`. Цифры, отдельная пунктуация и нелатинские слова не подходят. Это фильтр токенов, а не доказательство языка слова.
2. Ctrl удерживается непрерывно в течение 500 мс, курсор остаётся на том же слове в пределах допуска. Допустимы оба порядка: сначала Ctrl, затем наведение; сначала наведение, затем Ctrl. При нажатии Ctrl таймер начинается заново.
3. После ожидания показывается «Переводим…» и отправляется один запрос либо используется кэш. До истечения задержки сетевого запроса нет.
4. Смена слова, движение больше допуска или отпускание Ctrl до завершения ожидания отменяют таймер. Повтор `keydown` не создаёт новые таймеры.
5. После отправки отпускание Ctrl само по себе не закрывает окно и не отменяет ответ: можно перейти к кнопке произношения. Повторного запроса для того же открытого слова нет.

Перемещение на новое слово при удерживаемом Ctrl запускает новое ожидание. Старый ответ не должен заменить результат нового слова. Для повторного открытия после Esc требуется новое нажатие Ctrl или переход на другое слово.

## Popup и взаимодействие

Показывать исходное слово, русский перевод MyMemory, источник перевода. При наличии — до трёх вариантов значения, до двух английских примеров Free Dictionary API / Wiktionary с атрибуцией и кнопку «Произнести по-английски». Качество оформления — словарная карточка; полное совпадение с интерфейсом и содержимым Google Translate не требуется.

Результат перевода появляется независимо от готовности примеров. Не генерировать примеры самостоятельно; не переводить их дополнительными запросами в v1. Если примеры недоступны, раздел скрывается. При отсутствии английского голоса кнопка недоступна с понятным пояснением. Автоматического воспроизведения нет.

Окно располагается над курсором, при нехватке места — ниже, целиком в viewport, с внутренней прокруткой длинного содержимого. Оно не перекрывает саму точку наведения. При переходе со слова к окну есть 300 мс; внутри окна оно остаётся открытым без Ctrl. Если курсор вне слова и popup по истечении этого времени, окно закрывается.

Esc, клик вне окна, прокрутка страницы, изменение размера окна, потеря фокуса вкладки или скрытие документа закрывают popup, сбрасывают таймер и инвалидируют ответ. Закрытие останавливает инициированную этим popup речь. Не перехватывать обычные ссылки, выделение, Ctrl+C и системное Ctrl+click на Mac; при появлении контекстного меню закрыть карточку. Фокус страницы автоматически не менять; кнопки имеют доступные имена.

Ошибки различаются: нет сети, тайм-аут, ограничение сервиса, слово не найдено, неожиданный ответ. Показывать короткое русское сообщение, не бесконечный спиннер. Повтор — новое явное наведение с Ctrl; автоматических ретраев нет.

## Область поддержки

V1 работает в основном фрейме обычных HTTP(S)-страниц с разрешённым доступом. Исключить поля ввода, пароли, `textarea`, `contenteditable` и собственный popup. Не сканировать страницу целиком. Слово должно находиться в одном текстовом узле; границы токена проверяются по фактическому прямоугольнику текста, чтобы не переводить соседнее слово из пробела.

Вне v1: iframe, Shadow DOM сайтов, canvas, изображения/OCR, PDF, страницы `chrome://`, Chrome Web Store, локальные файлы и инкогнито. Не обещать работу там, где Chrome не разрешает внедрение.
