# Провайдеры и проверка интеграции

## Принцип выбора

Нужен перевод EN → RU без оплаты, обязательной карты и собственного сервера. Google Translate предпочтителен, но пользователь разрешил другой бесплатный API. Функциональность сайта Google Translate, API перевода и словарь с примерами — разные источники; не обещать их эквивалентность.

Источники и живые запросы проверены 2026-10-17. Выбран **MyMemory**, дополнения — **Free Dictionary API**, произношение — локальный **Chrome TTS**. Перевод и примеры получены через установленное MV3-расширение в Chrome владельца. Доступность и состав ответов могут меняться.

## Перевод

| Кандидат | Что известно | Решение для v1 |
| --- | --- | --- |
| Google Cloud Translation | Официальный API с бесплатной квотой, но требует включённого биллинга | Не подключать для этого MVP |
| Неофициальный веб-интерфейс Google Translate | Нет подтверждённого публичного контракта для нашего расширения | Не используется: для личного MVP найден работающий API без такой зависимости |
| MyMemory | Живой анонимный GET вернул EN → RU без ключа, аккаунта или карты | Выбран; HTTP 429 и `quotaFinished` останавливают запросы с понятным сообщением |

У Google Cloud есть ежемесячная бесплатная квота для NMT, однако это не сервис без биллинга: [официальная настройка](https://docs.cloud.google.com/translate/docs/setup), [тарифы](https://cloud.google.com/products/translate/pricing).

Первичный источник о стороннем клиенте Google — [репозиторий googletrans](https://github.com/ssut/py-googletrans). Его авторы называют интерфейс неофициальным и предупреждают о нестабильности. Это не документация Google и не подтверждение разрешённости или работоспособности конкретного endpoint для нашего приложения. Не переносить Python-клиент в расширение и не копировать обходы блокировок.

[Спецификация MyMemory](https://mymemory.translated.net/doc/spec.php) и [лимиты](https://mymemory.translated.net/doc/usagelimits.php) при текущем чтении вернули 403. Точную действующую дневную квоту и полные условия здесь не заявляем подтверждёнными. Бесплатный анонимный доступ подтверждён фактическими ответами API; это не гарантия бессрочной бесплатности или SLA. Подходит для небольшого личного использования при сохранении доступности, без автоматической оплаты при исчерпании квоты.

## Примеры и произношение

[Free Dictionary API](https://dictionaryapi.dev/) документирует `GET https://api.dictionaryapi.dev/api/v2/entries/en/<word>` с английскими значениями, примерами и фонетикой. Сервис заявлен бесплатным. Получены два примера для `hello`; ответ содержит источник Wiktionary и CC BY-SA 3.0, которые показываются рядом с примерами. Это отдельный английский словарь; русский перевод от него не зависит. Наполнение слов и доступность не гарантированы. В Chrome наблюдался временный сетевой сбой: новый явный поиск впоследствии получил примеры; скрытые ретраи не добавлялись.

Кнопка использует `chrome.tts`: доступный локальный английский голос (`remote === false`), предпочтительно `en-US`, затем другой `en-*`. Если его нет, показывается «Английский голос недоступен». Сетевые голоса не включаются. Произносится только исходное слово по клику. Это синтез речи системы/Chrome, а не аудиозапись Google Translate. [API TTS](https://developer.chrome.com/docs/extensions/reference/api/tts).

Аудиоссылки из словаря в v1 не загружаем: так не нужны дополнительные медиа-домены и проверка произвольных URL. Выбор голоса и завершение речи проверены на целевом Mac; ошибки и отмена — автономными тестами.

## Результат HT-01

Endpoint: `GET https://api.mymemory.translated.net/get?q=<word>&langpair=en%7Cru`. Дополнительных параметров, email и ключа нет. Схема: `{responseStatus: 200, quotaFinished: false, responseData: {translatedText: "…"}, matches: [...]}`. `matches` используется только для вариантов того же слова EN → RU; API перевода не обещает примеров.

Живая выборка через `npm run check:providers`: `hello` → «Алло», `bank` → «банк», `run` → «бегу», `don't` → «не», `well-known` → «Известный эксперт», `qzxwvv` → `NOT_FOUND` после нормализации ответа. Последний содержательный пример показывает ограничение качества: перевод одиночного слова может быть контекстно неточным. Не исправляем ответы произвольными встроенными переводами и не приписываем их Google.

В Chrome проверены перевод `hello`, вариант «здравствуйте», два примера, наличие локального английского голоса и завершение TTS без ошибки. Реальные публичные ответы сохранены в `tests/fixtures/mymemory-hello.json` и `tests/fixtures/dictionary-hello.json`; HTTP 429, тайм-аут и некорректный JSON моделируются автономными тестами. Никаких оплачиваемых аккаунтов, обходов ограничений или секретов не создано.
