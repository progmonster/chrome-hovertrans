# Провайдеры и проверка интеграции

## Принцип выбора

Нужен перевод EN → RU без оплаты, обязательной карты и собственного сервера. Google Translate предпочтителен, но пользователь разрешил другой бесплатный API. Функциональность сайта Google Translate, API перевода и словарь с примерами — разные источники; не обещать их эквивалентность.

Источники изучены 2026-10-17. Это проверка документации, а не доказательство доступности API из расширения и сети владельца. Реальные запросы и прототип выполняются в HT-01 следующего этапа.

## Перевод

| Кандидат | Что известно | Решение для v1 |
| --- | --- | --- |
| Google Cloud Translation | Официальный API с бесплатной квотой, но требует включённого биллинга | Не подключать для этого MVP |
| Неофициальный веб-интерфейс Google Translate | Используется сторонними клиентами; нет подтверждённого публичного контракта для нашего расширения и гарантии доступности | Первый кандидат для небольшого технического исследования; пока не выбран окончательно |
| MyMemory | Кандидат на альтернативный API | Проверить документацию, условия, лимиты и фактический ответ в HT-01; сейчас не подключён |

У Google Cloud есть ежемесячная бесплатная квота для NMT, однако это не сервис без биллинга: [официальная настройка](https://docs.cloud.google.com/translate/docs/setup), [тарифы](https://cloud.google.com/products/translate/pricing).

Первичный источник о стороннем клиенте Google — [репозиторий googletrans](https://github.com/ssut/py-googletrans). Его авторы называют интерфейс неофициальным и предупреждают о нестабильности. Это не документация Google и не подтверждение разрешённости или работоспособности конкретного endpoint для нашего приложения. Не переносить Python-клиент в расширение и не копировать обходы блокировок.

[Спецификация MyMemory](https://mymemory.translated.net/doc/spec.php) и [лимиты](https://mymemory.translated.net/doc/usagelimits.php) при текущем чтении вернули 403. Поэтому конкретные квоты, отсутствие ключа и пригодность здесь не считаются проверенными. Проверить их до выбора; недоступность страницы документации не доказывает недоступность API.

## Примеры и произношение

[Free Dictionary API](https://dictionaryapi.dev/) документирует `GET https://api.dictionaryapi.dev/api/v2/entries/en/<word>` с английскими значениями, примерами и фонетикой. Сервис заявлен бесплатным. Это источник английских примеров, а не русский переводчик; наполнение отдельных слов и доступность не гарантированы. Пригодность, условия атрибуции/лицензии и лимиты проверить в HT-01; показывать доступную атрибуцию. Не отправлять запрос примеров, если он не включён после проверки. Ответы словаря не должны блокировать основной перевод.

План для кнопки — `chrome.tts`: выбрать доступный английский голос (`en-US`, затем другой `en-*`), предпочитать локальный (`remote === false`). В v1 использовать только доступный локальный голос; если его нет, показать «Английский голос недоступен». Не включать сетевой голос незаметно. Произносить только исходное слово по клику. Это синтез речи системы/Chrome, а не аудиозапись Google Translate. [API TTS](https://developer.chrome.com/docs/extensions/reference/api/tts).

Аудиоссылки из словаря в v1 не загружаем: так не нужны дополнительные медиа-домены и проверка произвольных URL. В HT-01 проверить обработку ошибок и выбор голоса на целевом Mac.

## Результат HT-01

В этой секции записать: выбранный провайдер, точный HTTPS-origin и путь, параметры EN → RU, пример схемы ответа без личных данных, ограничения и дату проверки. Зафиксировать, что действительно возвращается: один перевод, варианты, примеры. Добавить обезличенные fixtures в будущий `tests/fixtures/`.

Минимальная выборка: `hello`, `bank`, `run`, `don't`, `well-known`, `qzxwvv`. Проверить нормальный ответ, отсутствие слова, тайм-аут, HTTP 429 и некорректный JSON; ошибки можно моделировать локально. Нужен запрос из MV3 worker, не только curl. Не включать автоматический fallback, обход CAPTCHA или платные услуги. Если бесплатный кандидат не подходит, записать причину и продолжать независимые части с явно обозначенной заглушкой; готовность MVP не отмечать.
