# Проверка и приёмка

## Соразмерные проверки

Команды: `npm test` — автономные тесты, `npm run build` — сборка, `npm run dev:fixture` — HTTP-fixture на 127.0.0.1:8765. `npm run check:providers` отдельно отправляет живые запросы для синтетических слов. Не вводим произвольный процент покрытия и не тестируем каждую строку документации.

После реализации чистую логику проверяем через `node:test`, сетевые ответы — fixtures и подменой fetch без живого API в обычном тестовом прогоне. Реальное извлечение слова, события Ctrl и отображение popup проверяются в Chrome: модульные тесты не доказывают работу DOM и разрешений.

Имена: `tests/hover-state.test.js`, `tests/word-boundaries.test.js`, `tests/translation-provider.test.js`. Описание теста говорит о результате, например «отпускание Ctrl до 500 мс отменяет запрос». Дополнительный браузерный фреймворк вводить только при явной пользе, не ради самого процесса.

## Минимальная автоматическая проверка

- 499 мс не вызывают запрос, 500 мс при соблюдении условий вызывают ровно один; допуск движения считается от исходной точки, а не каждого последнего события.
- Отпускание Ctrl, смена слова, blur и Esc сбрасывают нужное состояние; повтор keydown не дублирует таймер.
- Ответ A не заменяет уже открытый B; отмена одной вкладки не ломает другую.
- Токены с апострофом/дефисом допустимы; пустые, слишком длинные и неподходящие отклоняются и в worker.
- Нормализация корректного ответа; пустой/неожиданный ответ, HTTP 429, сетевой сбой и тайм-аут обрабатываются без падения.
- Кэш учитывает провайдера/направление, TTL и размер; повторное наведение не создаёт лишний запрос.
- Разметка провайдера отображается текстом; сообщение не позволяет подставить произвольный URL или отправить текст страницы.

## Ручная приёмка MVP

Проводить на собственной HTML-fixture и минимум одной обычной HTTPS-странице без чувствительных данных. После сборки загрузить `dist/` в `chrome://extensions`, затем обновить проверяемые страницы. Кнопка проверки на fixture отправляет синтетические DOM-события установленному content script, не подменяя API. Снимок последней карточки на fixture статический; реальный popup расположен отдельно над словом.

| Проверка | Ожидаемый результат |
| --- | --- |
| Наведение без Ctrl; Command на Mac | Нет popup и запросов |
| Оба порядка Ctrl/наведение, остановка 500 мс | Одна карточка с EN → RU |
| Движение, пробел рядом со словом, смена слова | Нет перевода соседнего слова и устаревшей карточки |
| `hello`, `bank`, `don't`, слово в ссылке | Корректное извлечение; обычный клик по ссылке работает |
| Отпустить Ctrl и перейти к popup | Можно нажать кнопку; окно не исчезает во время перехода до 300 мс |
| Углы viewport, zoom 200%, длинный результат | Окно остаётся доступным, текст читается, кнопки доступны |
| Esc, внешний клик, scroll, resize, blur | Закрытие, сброс ожидания и отсутствие позднего открытия |
| Поле ввода, пароль, редактор, кириллица | Нет перевода и запросов |
| Ctrl+C, выделение, Ctrl+click на Mac | Базовое поведение сайта/системы сохраняется |
| Пример есть / отсутствует / сервис не отвечает | Перевод остаётся; источник примера обозначен, пустой раздел скрыт |
| Кнопка речи, нет голоса, ошибка TTS | Английская речь только по клику либо понятное недоступное состояние |
| Отключить сеть, смоделировать тайм-аут/429 | Короткая ошибка, нет бесконечных повторов |
| Worker остановлен, затем новое наведение | Новая активация работает; потеря кэша допустима |
| Две вкладки, быстрые переходы A → B | Изоляция запросов и корректный актуальный ответ |

В DevTools worker проверить, что уходят только слово и фиксированные языки, запросы идут только к выбранным origin, нет cookies/контекста страницы в отправляемых приложением данных. Проверить манифест, отсутствие remote code и скрытых ретраев. Не сохранять скриншоты с личными страницами и сырые пользовательские слова в логи.

## Запись результата

В соответствующей задаче: дата; версия Chrome и ОС; команды и итог; какие ручные сценарии проверены; известные ограничения. Не отмечать всю матрицу пройденной по одному успешному переводу. Ручную приёмку владельца, если она ещё не выполнена, явно оставить открытой в HT-08.

## Проверка реализации 2026-10-17

Окружение: Node 24.18.1, npm 12.0.2, Chrome 155.0.8059.80, macOS 26.6.2. Расширение загружено через «Load unpacked» из локального `dist/`.

- `npm test`: 23 теста без сети. Включают время/сбросы/дрожание, блокировку повторного открытия, валидацию слов и сообщений, кэш, изоляцию отмены между вкладками, 429/cooldown, сетевые ошибки, повреждённый JSON, тайм-аут, атрибуцию и безопасность ссылок, выбор только локального голоса, асинхронную ошибку TTS и отмену речи до получения голосов.
- `npm run build`: создаёт три файла `dist/manifest.json`, `dist/content.js`, `dist/background.js` без runtime-зависимостей.
- `npm ci` воспроизвёл зависимости по lockfile; после него `npm test` и `npm run build` повторно прошли. В этой среде npm блокирует postinstall esbuild, но установленного платформенного optional-пакета достаточно для сборки; разрешать дополнительные install scripts не потребовалось.
- `npm run check:providers`: все шесть слов обработаны, неизвестное слово — `NOT_FOUND`; для `hello` получены два лицензированных примера. Это отдельная проверка из Node, не замена браузерной.
- В Chrome fixture через синтетические события проверила: отсутствие карточки без Ctrl и до задержки; отмену при раннем отпускании; сохранение карточки после отпускания; живой перевод; положение внутри viewport; Esc; исключение обычного поля; завершение речи API без ошибки. Отдельно визуально осмотрена реальная карточка с двумя примерами и ссылками CC BY-SA 3.0.
- В HTTPS-контексте `https://example.com/` через установленный content script получено `domain → домен`; результат зафиксирован тестовым текстом на странице. Для теста отправлялись синтетические события из DevTools, API и worker оставались настоящими.
- Историческая браузерная ошибка `Illegal invocation` выявлена первым прогоном и исправлена обёртками вокруг `setTimeout`/`clearTimeout`: браузерные функции нельзя вызывать с экземпляром состояния в качестве `this`.
- Для словаря наблюдалась ошибка `NETWORK` в первом поиске и успешный ответ при следующем явном поиске. Сбой не затронул перевод; автоматические ретраи не добавлены.
- Заключительный прогон финальной сборки: перевод «Алло», два примера, локальный голос и завершение речи успешны. После очистки исторической исправленной ошибки страница Errors этого расширения новых записей не показала. Chrome оставлен на локальной fixture для проверки владельцем.
- Просмотрены манифест и сетевые адаптеры: только два API-origin, одно слово, фиксированные языки, `credentials: omit`, `no-referrer`, без произвольного URL и удалённого кода. Автономный тест проверяет фактические параметры передаваемого `fetch`. Это не утверждение о полном перехвате браузерного трафика в DevTools.

**Оставлено владельцу:** физическое удержание только Ctrl, удобство перехода мышью к popup, системные Ctrl+C/Ctrl+click, zoom 200% и крайние размеры окна. Инструмент управления Chrome отклоняет нажатие одиночного модификатора (`keyPressIncludedNoNonModifierKeys`); синтетические события этого не доказывают. Полная матрица выше не объявляется пройденной. По разрешённому владельцем варианту расширение передаётся для такой ручной проверки; это не блокирует готовую локальную сборку.
