# Проверка и приёмка

## Соразмерные проверки

Сейчас проверяются документы, локальные ссылки и Git diff. Тестов приложения ещё нет. HT-02 должен добавить реальные команды `npm test` и `npm run build`; до этого они являются планом. Не вводим произвольный процент покрытия и не тестируем каждую строку документации.

После реализации чистую логику проверяем через `node:test`, сетевые ответы — fixtures и подменой fetch без живого API в обычном тестовом прогоне. Реальное извлечение слова, события Ctrl и отображение popup проверяются в Chrome: модульные тесты не доказывают работу DOM и разрешений.

Имена: `tests/hover-state.test.js`, `tests/word-boundaries.test.js`, `tests/translation-provider.test.js`. Описание теста говорит о результате, например «отпускание Ctrl до 500 мс отменяет запрос». Дополнительный браузерный фреймворк вводить только при явной пользе, не ради самого процесса.

## Минимальная автоматическая проверка

- 499 мс не вызывают запрос, 500 мс при соблюдении условий вызывают ровно один; допуск движения считается от исходной точки, а не каждого последнего события.
- Отпускание Ctrl, смена слова, blur и Esc сбрасывают нужное состояние; повтор keydown не дублирует таймер.
- Ответ A не заменяет уже открытый B; отмена одной вкладки не ломает другую.
- Токены с апострофом/дефисом допустимы; пустые, слишком длинные и неподходящие отклоняются и в worker.
- Нормализация корректного ответа; пустой/неожиданный ответ, HTTP 429, сетевой сбой и тайм-аут обрабатываются без падения.
- Кэш учитывает провайдера/направление, TTL и размер; повторное наведение не создаёт лишний запрос.
- Разметка провайдера отображается текстом; сообщение не позволяет подставить произвольный URL или отправить текст страницы.

## Ручная приёмка MVP

Проводить на собственной HTML-fixture, обслуживаемой через localhost HTTP, и минимум одной обычной HTTPS-странице без чувствительных данных. Команду запуска fixture добавить вместе с HT-02. После сборки загрузить `dist/` в `chrome://extensions`, затем обновить проверяемые страницы.

| Проверка | Ожидаемый результат |
| --- | --- |
| Наведение без Ctrl; Command на Mac | Нет popup и запросов |
| Оба порядка Ctrl/наведение, остановка 500 мс | Одна карточка с EN → RU |
| Движение, пробел рядом со словом, смена слова | Нет перевода соседнего слова и устаревшей карточки |
| `hello`, `bank`, `don't`, слово в ссылке | Корректное извлечение; обычный клик по ссылке работает |
| Отпустить Ctrl и перейти к popup | Можно нажать кнопку; окно не исчезает во время перехода до 300 мс |
| Углы viewport, zoom 200%, длинный результат | Окно остаётся доступным, текст читается, кнопки доступны |
| Esc, внешний клик, scroll, resize, blur | Закрытие, сброс ожидания и отсутствие позднего открытия |
| Поле ввода, пароль, редактор, кириллица | Нет перевода и запросов |
| Ctrl+C, выделение, Ctrl+click на Mac | Базовое поведение сайта/системы сохраняется |
| Пример есть / отсутствует / сервис не отвечает | Перевод остаётся; источник примера обозначен, пустой раздел скрыт |
| Кнопка речи, нет голоса, ошибка TTS | Английская речь только по клику либо понятное недоступное состояние |
| Отключить сеть, смоделировать тайм-аут/429 | Короткая ошибка, нет бесконечных повторов |
| Worker остановлен, затем новое наведение | Новая активация работает; потеря кэша допустима |
| Две вкладки, быстрые переходы A → B | Изоляция запросов и корректный актуальный ответ |

В DevTools worker проверить, что уходят только слово и фиксированные языки, запросы идут только к выбранным origin, нет cookies/контекста страницы в отправляемых приложением данных. Проверить манифест, отсутствие remote code и скрытых ретраев. Не сохранять скриншоты с личными страницами и сырые пользовательские слова в логи.

## Запись результата

В соответствующей задаче: дата; версия Chrome и ОС; команды и итог; какие ручные сценарии проверены; известные ограничения. Не отмечать всю матрицу пройденной по одному успешному переводу. Ручную приёмку владельца, если она ещё не выполнена, явно оставить открытой в HT-08.
